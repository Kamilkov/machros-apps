## Design Specificity Verdict
Authored copy on an interchangeable shell. Copy is highly specific and does the persuasion; visuals (system font, gray cards, amber accent, gem emoji) would survive a logo swap. Detector: clean, 0 findings, no false positives. Note: og.png exists (Assessment A flagged it unverified — false alarm).

## Priority Issues
- [P1] Tesouros has no acquisition link — only action is the privacy policy. Fix: App Store link or explicit "Coming to the App Store".
- [P1] Fragmented identity: machros / Somil SLU / somil-and.com / repo Kamilkov/subscriptions-dashboard for "UsageBar". Fix: one connecting copy line + honest link label "Download from GitHub".
- [P2] No screenshots for three visual products. Fix: one small lazy-loaded image per card.
- [P2] CTA inconsistency across cards. Fix: uniform primary action per card, consistently styled.
- [P3] Link contrast ~3.6:1 on light; tiny tap targets. Fix: light-dark(#a86315, #c47c26), padded links.
